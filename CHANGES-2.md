# JournalTrace fork — filter and tree fixes

Changes:
- Drive and numeric tree identifiers use a soft gray color.
- Directory and file names use white text.
- Reason filters are mutually exclusive and cannot be turned off by clicking the active filter again.
- `Rename: new name` matches both `Rename: new name` and `Rename: new name | Close`.
- `Rename: old name` matches exactly `Rename: old name`.
- `File delete | Close` remains supported.
