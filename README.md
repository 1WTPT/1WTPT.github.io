# 1WantToPiglet site + JournalTrace fork

## Редизайн
Визуальная концепция — «приборная панель диспетчера»: обсидиановый фон,
латунные акценты, шрифты Unbounded / Onest / JetBrains Mono. Карточки и
панели получили лёгкий 3D-наклон и скользящий блик при наведении курсора
(библиотека `assets/vendor/jquery.plate.js`, обёрнута в `assets/site.js`).

Набор из десяти цветовых скинов заменён на одну выверенную пару
светлый/тёмный — так фирменный стиль не размывается произвольным выбором
пользователя. Вся функциональность (вход по паролю с привязкой к IP,
копирование фильтров, простой режим, расчёт КПД с сохранением
коэффициентов) сохранена без изменений.

## Сборка JournalTrace
Откройте PowerShell в корне репозитория и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Build-JournalTrace.ps1
```

Скрипт собирает Release и копирует файл в `downloads/JournalTrace.exe`, после чего ссылка на странице `/forks/` начинает работать.
